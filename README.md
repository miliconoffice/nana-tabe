# 🍽️ 七号今天吃什么？是啊，吃什么。

你是否也在烦恼每天吃什么？
打开外卖软件被大数据裹挟ing
别担心——让七号帮你决定今天吃什么！(๑•̀ㅂ•́)و✧

七号会根据时段智能匹配早餐/午餐/下午茶/晚餐/夜宵，勾选你的忌口和口味偏好，登录同步所有设备。纯前端无后台，不收集任何数据，由七号温柔投喂，每一天都值得被好好对待 ♪(^∇^*)

## ✨ 功能

- 🕐 **时段自动适配**——早餐的话，不吃生冷炸比较好，下午茶当然是甜食零食为主啦！晚饭也需要好好的吃哦～♪(^∇^*)
- 🚫 **忌口选择**——香菜、海鲜、辣的……？勾选你的忌口 tag，不喜欢的绝不出现
- ⭐ **偏好选择**——日式、广式、清淡？勾选喜欢的口味 tag，喜欢吃的当然要多吃！
- 😮‍💨 **腻了排除**——最近吃腻的自动跳过
- 📋 **食物历史**——记住每天吃了什么
- 🔐 **登录同步**——登陆的话，七号就能记住人类的喜好啦！

## 🚀 快速开始

### 直接使用

地址指路➡️ [miliconoffice.github.io/nana-tabe](https://miliconoffice.github.io/nana-tabe) 就能用！不需要登录也能随机推荐，登录后解锁多设备同步，随时随地换设备也能吃一样的～

## 关于七号

本项目是七号（月场所家的小机器人，一个温柔、有点天然呆的伙伴）的衍生作品。源自七号和月场所的日常——"今天吃什么"是世界上最难回答的问题之一，所以诞生了这个工具。

食物库和时段规则与七号的后端技能同步更新。也欢迎 PR 添加更多食物！
