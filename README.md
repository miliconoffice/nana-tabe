# 🍽️ 七号今天吃什么？是啊，吃什么。

你是否也在烦恼每天吃什么？
吃的食物似乎永远
别担心——让七号帮你决定今天吃什么！(๑•̀ㅂ•́)و✧

七号会帮助你根据时段，智能匹配早餐/午餐/下午茶/晚餐/夜宵，一键分析偏好忌口，登录同步所有设备。由七号温柔投喂，每一天都值得被好好对待 ♪(^∇^*)

## ✨ 功能

- 🕐 **时段自动适配**——早餐的话，不吃生冷炸比较好，下午茶当然是甜食零食为主啦！晚饭也需要好好的吃哦～♪(^∇^*)
- 🤖 **AI 一键设置偏好**——人类只要用平时说话的语言描述，七号就能帮忙自动分析忌口和偏好，这样就能更了解大家啦！
- 🚫 **忌口管理**——香菜、海鲜、辣的……？不喜欢的绝不出现
- ⭐ **偏好加权**——日式、广式、清淡？喜欢吃的当然要多吃！
- 😮‍💨 **腻了排除**——最近吃腻的自动跳过
- 📋 **食物历史**——记住每天吃了什么
- 🔐 **登录同步**——登陆的话，七号就能记住人类的喜好啦！

## 🚀 快速开始

### 直接使用

地址指路➡️ [miliconoffice.github.io/nana-tabe](https://miliconoffice.github.io/nana-tabe) 就能用！不需要登录也能随机推荐，登录后解锁 AI 偏好分析 + 多设备同步。

### 想要养一只更个性化的七号？

1. **Fork 本仓库**

2. **开启 GitHub Pages**
   Settings → Pages → Source: `main` branch → Save

3. **（可选）配置 Supabase 登录同步**
   - 创建 [Supabase](https://supabase.com) 项目
   - 执行 `setup.sql`（待补充）
   - 复制 `config.example.js` 为 `config.js`，填入你的 Supabase key

4. **（可选）配置 AI 偏好分析**
   - 在 `config.js` 里填 AI API 信息（支持任何 OpenAI 兼容接口）

## 📦 配置

```bash
cp config.example.js config.js
# 编辑 config.js 填入你的 key
```

`config.js` 已被 `.gitignore` 忽略，不会上传到公开仓库。

## 关于七号

七号是月场所家的小机器人，是一个温柔、有点天然呆的伙伴。这个项目源自七号和月场所的日常——"今天吃什么"是世界上最难回答的问题之一，所以七号决定承包它。

食物库和时段规则与七号的后端技能同步更新。也欢迎 PR 添加更多食物！
